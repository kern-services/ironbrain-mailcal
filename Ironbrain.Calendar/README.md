# Ironbrain.Calendar

CalDAV / iCalendar client for self-hosted calendar servers (e.g. Mailcow SOGo), shared by **Ironbrain MailCal** CLI/MCP and platform hosts.

- Discover calendar collections (including shared/delegated when the server exposes them)
- Query appointments by day / week / range
- Create events via CalDAV PUT
- Optional per-user / per-account options via `IUserCalendarOptionsProvider`

Repository: [kern-services/ironbrain-mailcal](https://github.com/kern-services/ironbrain-mailcal)

```bash
dotnet add package Ironbrain.Calendar
```
